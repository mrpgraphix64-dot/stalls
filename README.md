# Reworkzone Stalls — Standalone Exhibition Portfolio

A premium, image-first, architectural portfolio website dedicated exclusively to showcasing Reworkzone's exhibition stalls, custom-built brand environments, 3D visualizations, and turnkey fabrication projects.

Built to run as a completely independent standalone website on the subdomain:
**`stalls.reworkzone.in`**

---

## 🌟 Key Features

1. **Editorial Masonry Gallery**:
   - Showcases 80+ verified project photographs and 3D architectural renders.
   - Dynamic 1–4 column responsive layout with native aspect ratio preservation.
   - Zero layout shift with responsive thumbnails (~34 KB average) and progressive load-more pagination.

2. **Full-Featured Lightbox**:
   - Deep-zoom high-resolution full-screen viewing.
   - Complete keyboard accessibility (Left/Right arrows, Escape to close).
   - Touch gesture swipe navigation for mobile & tablet visitors.
   - Visible image counter (`1 / 80`) and verified project metadata.
   - "Discuss This Stall" direct CTA linking into the enquiry form.

3. **Multi-Angle Project Case Studies**:
   - Switch between **Gallery View** and **Case Studies View** with one click.
   - Dedicated project modals for stalls with multiple views (Radix 3D designs, Techify S6, AppAspect corner booth, Syndell, Technobrains, MagnusMinds, UXTeam, Benefex London, Chambury Birmingham).
   - Technical fabrication specs, event details, venue, and year.

4. **Dynamic Categories & Instant Search**:
   - All Projects (80 items)
   - Custom Exhibition Stalls (25 items)
   - Tech & Corporate Expo (16 items)
   - 3D Concepts & Renders (14 items)
   - International Exhibitions (ExCeL London & NEC Birmingham)
   - Brand Pavilions & Activations (23 items)
   - Instant real-time keyword search by client name, booth number, city, or specs.

5. **Cinematic Hero**:
   - Architectural photography collage with verified project imagery.
   - Direct CTAs: `EXPLORE OUR WORK` and `PLAN YOUR EXHIBITION`.
   - Real metrics (80+ project views, turnkey delivery, India & UK track record).

6. **Services & Process**:
   - 8 key capabilities (3D Design, Custom Fabrication, Modular Systems, Backlit Graphics, Turnkey Installation, Safety Compliance).
   - 5-step visual delivery workflow (Brief → Concept → 3D Visualization → Fabrication → Handover).

7. **Lead Generation & Enquiry**:
   - Verified fields: Name, Email, Company, Phone, Event Name, Event City, Stall Dimensions (presets: 3x3m, 6x3m, 6x6m, 9x6m, 12x6m+), Expected Date, Requirements.
   - Client-side validation, anti-spam honeypot, submission loading state, and verified success card.
   - Instant WhatsApp one-click inquiry button (+91 84010 60482) pre-populating stall dimensions and notes.

8. **Performance & Asset Optimization**:
   - Original bulk assets (~367 MB) converted into optimized WebP derivatives.
   - Full HD views: 10.71 MB total.
   - Thumbnails: 2.73 MB total (~34 KB/image).
   - Over 97% bandwidth reduction with zero perceptible quality loss.
